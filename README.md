# 水磨 SHUIMO — 机构复刻 No.09

王祯《农书》水磨(「水轮三事」之一):立式水轮下缘入水,同轴直驱上磨
(1:1,磨速=轮速),磨齿研麦出粉。出粉率 ∝ ω×磨径可验算。B 键查看总图。

## 机构与验算

```
尺寸(演示值):
  立轮   R 1.15 m(径 2.3 m)· 12 辐 8 叶 · 入水 0.25 m
  立轴   Ø0.13 × 1.7 m,同轴直驱(1:1,无变速)
  磨盘   上磨 R 0.55(磨齿 8 道)旋于下磨 R 0.60 之上,间隙 0.10

出粉验算(载入期断言):
  磨速 = 轮速(同轴 1:1)
  出粉率 = 2.4 × ω/ω快(粒/s,线性)
  15s 模拟累计与 ω·t 一致(±3)
```

## 试验段(时间线 44s 循环)

| 键 | 阶段 | 内容 |
| --- | --- | --- |
| 1-2 | 装配 | 支架磨台 → 立轮 |
| 3-4 | 装配 | 立轴 → 下磨上磨合拢 + 麦粒漏斗 |
| 5 | 慢磨 | ω 0.85(8.1 RPM) |
| 6 | 快磨 | ω 1.5(14.3 RPM),出粉粒子 |
| 7 | 特写 | 磨齿 8 道近观 |
| 8 | 总结 | 直驱 1:1 |

仪表盘:轮/磨转速、出粉累计曲线、传动链示意(三级角标)、磨盘俯视。
